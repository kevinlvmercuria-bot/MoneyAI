## 已完成的运行验证

本轮功能实施阶段已完成桌面与 390px 页面操作、员工与管理员权限、Excel 模板下载及导入、企微设置不回显与即时应用、受控接口测试向导、数据迁移内容核对和 PostgreSQL 备份恢复验证。

真实企业微信发送、门店 HTTPS 回调联调及云端部署没有作为本次发布验收成功项。源码使用者仍需配置自己的目标数据库、平台权限、凭据及测试客户。

## 使用入口

完整克隆仓库后按 README 准备配置与模拟资料。GitHub 自动源码压缩包不带 Git 历史，不能直接用于历史模拟资料恢复。已有 SQL Server 用户先按迁移指南搬迁，已有 PostgreSQL 用户先备份数据库、配置与加密密钥，再运行增量迁移并重启。
