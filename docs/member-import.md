# 真实会员导入

管理员在「会员档案」点击「导入真实会员」。员工不能导入，分享版不处理真实文件。

1. 下载 Excel 或 CSV 模板，填写会员资料。支持 `.xlsx` 和 UTF-8 / GB18030 CSV，不支持旧 `.xls`、加密 Excel 或公式单元格。
2. 选择文件并读取，核对自动识别的字段映射。第一张工作表、第一行作为表头；每批最多 500 位、50 列，上传文件最多 5 MB。
3. 预览并修正错误，勾选已核对后确认导入。存在错误时整个批次不写入会员档案；同一批次重复提交不会重复新增。

姓名和手机号必填。可选字段包括会员等级、余额、累计消费、偏好款式、偏好技师、入会日期、最近到店、营销授权、护理回访授权和备注。金额使用非负数，最多两位小数；日期使用 `YYYY-MM-DD` 或 Excel 日期单元格。手机号建议使用文本格式。

本期只新增会员，不覆盖已有档案。文件内或现有档案中手机号重复时显示错误；同一份完整数据已导入过时会提示，避免重复导入。缺少授权字段或留空时按未授权处理，不自动同意营销或护理回访。

导入的数据标记为真实会员，沿用系统会员编号。导入“最近到店”不创建已完成服务订单，也不凭此触发护理回访。服务完成仍按原流程登记，联系限制继续生效。

预览在服务端暂存一小时，下一次上传时清理过期预览。成功导入后删除该批次暂存的原始行，仅保留数量、会员 ID、提交人及文件内容摘要；正式会员资料保存在既有工作台状态中。错误预览最多展示前 200 条问题，数据预览展示前 100 行。

维护入口：`server/member-import.js` 处理解析和事务导入，`server/member-import-routes.js` 校验管理员权限；`public/app/member-import.js` 负责上传、映射、预览及确认。`server/admin-import.test.js` 覆盖 Excel/CSV、权限、重复、错误与真实数据标记。

接口位于 `/api/team/import`：模板 GET `template/xlsx`、`template/csv`；读取文件 POST `inspect?format=xlsx|csv`（二进制请求）；预览 POST `preview`；确认 POST `commit`。字段映射和确认版本由服务端复核，不接受网页直接提交“已通过校验”的标记。
